# Snapp Voice 16000

Independent Android app that reads Snapp Driver trip offers using Accessibility.

- Destination trip distance only (the second distinct distance shown in the offer, when present).
- 16,000 toman/km or higher: Persian voice says «خوبه».
- Below 16,000 toman/km: Persian voice says «بده».
- Speaks once per offer.
- Separate application ID: com.snapfloat.voice16000.

Enable the app's Accessibility service and make sure a Persian text-to-speech voice is installed on the phone.
