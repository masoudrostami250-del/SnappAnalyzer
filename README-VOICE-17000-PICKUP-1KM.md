# Snapp Voice 17000 + Pickup 1km

نسخه مستقل برنامه تحلیل صوتی سفر اسنپ با صدای زن فارسی آفلاین.

## قوانین
- اگر فاصله مبدأ حداکثر ۱ کیلومتر باشد و کرایه مقصد به‌ازای هر کیلومتر حداقل ۱۷٬۰۰۰ تومان باشد: «برو».
- اگر فاصله مبدأ بیشتر از ۱ کیلومتر باشد: «نرو».
- اگر نرخ مقصد کمتر از ۱۷٬۰۰۰ تومان برای هر کیلومتر باشد: «نرو».
- نرخ فقط از تقسیم کرایه بر مسافت مقصد به دست می‌آید؛ مسافت مبدأ به مسافت مقصد اضافه نمی‌شود.
- برای تأیید سفر باید هر دو فاصله مبدأ و مقصد قابل تشخیص باشند.

شناسه اندروید این نسخه: `com.snapfloat.voice17000pickup1km`

شاخه مستقل: `voice-17000-pickup-1km-female-v1`

این نسخه از شاخه ۲ کیلومتر جدا ساخته شده و تغییرات آن روی نسخه قبلی اعمال نمی‌شود.
